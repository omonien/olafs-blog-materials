# Fact table: Firebird and PostgreSQL

State checked on **4 November 2026**. Versions: Firebird **5.0.4** (17 April 2026, current), PostgreSQL **18.6** (13 August 2026, current minor). Firebird 6.0 and PostgreSQL 19 are not released; where they change a row, it says so. Facts only, each with its source; opinions belong in the post.

Abbreviations for frequent sources:

- **FB-RN50**: [Firebird 5.0 release notes](https://firebirdsql.org/file/documentation/release_notes/html/en/5_0/rlsnotes50.html), **FB-RN40**: [4.0 release notes](https://firebirdsql.org/file/documentation/release_notes/html/en/4_0/rlsnotes40.html), **FB-RN30**: [3.0 release notes](https://firebirdsql.org/file/documentation/release_notes/html/en/3_0/rlsnotes30.html)
- **FB-CONF**: [`firebird.conf` as shipped with 5.0.4](https://github.com/FirebirdSQL/firebird/blob/v5.0.4/builds/install/misc/firebird.conf), **FB-ROAD**: [Firebird 6 roadmap](https://www.firebirdsql.org/en/roadmap-v6/) (page dated October 2026)
- **PG-RN18**: [PostgreSQL 18 release notes](https://www.postgresql.org/docs/18/release-18.html), **PG-DOC**: [PostgreSQL 18 documentation](https://www.postgresql.org/docs/18/), **PG-SEC**: [PostgreSQL security page](https://www.postgresql.org/support/security/)

## Security

| Topic | Firebird | PostgreSQL |
| --- | --- | --- |
| Encryption at rest | Plugin API since 3.0 (data, index and blob pages). No usable plugin ships: the bundled example is a single-byte XOR. Commercial plugins: IBSurgeon (AES-256, EUR 1,699 per company), IBPhoenix. Sort files of an encrypted database stay unencrypted ("won't fix"). FB-RN30, [example ReadMe](https://github.com/FirebirdSQL/firebird/blob/v5.0.4/examples/dbcrypt/ReadMe.txt), [IBSurgeon](https://www.firebirdsql.org/encryption-plugin-framework-for-firebird), [#5579](https://github.com/FirebirdSQL/firebird/issues/5579) | No transparent data encryption in community PostgreSQL, also not in 19. Options: file system or block device encryption, pgcrypto for columns, vendor builds (Percona pg_tde on Percona Server 17/18, EDB, Fujitsu). Managed services encrypt storage by default. [Encryption options](https://www.postgresql.org/docs/18/encryption-options.html), [pg_tde](https://docs.percona.com/pg-tde/index.html), [EDB TDE](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/support/) |
| Encryption on the wire | Own wire encryption, key from the SRP login, no certificates: ChaCha64 (5.0), ChaCha (4.0), Arc4. Server default `WireCrypt = Required`. No TLS (request closed "won't fix"). FB-CONF, FB-RN40, [#3619](https://github.com/FirebirdSQL/firebird/issues/3619) | TLS (minimum TLS 1.2 by default) with server and client certificates, GSSAPI encryption, SCRAM channel binding. Off unless configured; libpq default `sslmode=prefer`. [Connection settings](https://www.postgresql.org/docs/18/runtime-config-connection.html), [libpq](https://www.postgresql.org/docs/18/libpq-connect.html) |
| Authentication | SRP (Srp256 default since 4.0), Windows SSPI (Kerberos before NTLM since 5.0.2), legacy (deprecated). No LDAP, no OAuth. FB-CONF, FB-RN50, [LDAP request #7326](https://github.com/FirebirdSQL/firebird/issues/7326) | SCRAM-SHA-256 (default since 14), LDAP, GSSAPI/Kerberos, SSPI, certificates, PAM, RADIUS (removed in 19), **OAuth 2.0 new in 18**; MD5 deprecated in 18. [Auth methods](https://www.postgresql.org/docs/18/auth-methods.html), [OAuth](https://www.postgresql.org/docs/18/auth-oauth.html), PG-RN18 |
| Authorization | Roles, default roles, roles granted to roles (4.0), system privileges (4.0), `SQL SECURITY DEFINER/INVOKER` (4.0). Column lists only for UPDATE and REFERENCES. **No row-level security.** FB-RN40, [Language reference](https://firebirdsql.org/file/documentation/html/en/refdocs/fblangref50/firebird-50-language-reference.html) | Roles, predefined roles, column privileges for SELECT/INSERT/UPDATE, `SECURITY DEFINER` functions, **row-level security since 9.5**. [GRANT](https://www.postgresql.org/docs/18/sql-grant.html), [RLS](https://www.postgresql.org/docs/18/ddl-rowsecurity.html) |
| Audit | Trace and audit built in (since 2.5): `AuditTraceConfigFile`, trace sessions with `fbtracemgr`, statement, transaction and connection events. FB-CONF, [fbtrace.conf](https://github.com/FirebirdSQL/firebird/blob/v5.0.4/src/utilities/ntrace/fbtrace.conf) | Logging settings (`log_statement`, `log_connections`, granular in 18); session and object audit through the pgAudit extension (14 to 19). [Logging](https://www.postgresql.org/docs/18/runtime-config-logging.html), [pgAudit](https://github.com/pgaudit/pgaudit) |
| Security history | 2017: two code execution flaws in the old UDF library; one (CVE-2017-11509) was not fixed, only mitigated by configuration. 2025: CVE-2025-54989 (unauthenticated crash, fixed about ten weeks after the report). 5.0.4, 4.0.7 and 3.0.14 (Apr 2026) fixed nine advisories at once: six let an attacker crash the server **without logging in** (CVSS vector PR:N), one more needs a user with INSERT privilege, CVE-2026-40342 (CVSS 9.9) lets users with `CREATE FUNCTION` run code on the server, CVE-2025-65104 is an information leak in the 3.0 client. [Advisories](https://github.com/FirebirdSQL/firebird/security/advisories), [Tenable TRA-2017-36](https://www.tenable.com/security/research/tra-2017-36), [ZDI-25-859](https://www.zerodayinitiative.com/advisories/ZDI-25-859/), [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-40342) | 3 to 8 CVEs per year from 2020 to 2025, **44 in 2026** (28 in 18.6 alone), many requiring a logged-in user. Fixes ship in the quarterly minor releases for all supported versions. PG-SEC |

## Data types and SQL

| Topic | Firebird | PostgreSQL |
| --- | --- | --- |
| JSON | **No JSON type and no JSON functions** in 5.0. JSON functions for 6.0 are an open pull request without review (June 2026); the author expects the JSON type to miss 6.0 and JSON to be stored as BLOB. Third party: UDR library udr-lkJSON. [Built-in functions 5.0.4](https://github.com/FirebirdSQL/firebird/blob/v5.0.4/doc/sql.extensions/README.builtin_functions.txt), [#5431](https://github.com/FirebirdSQL/firebird/issues/5431), [PR #9062](https://github.com/FirebirdSQL/firebird/pull/9062) | `json` (9.2) and `jsonb` (9.4), GIN indexes (`jsonb_ops`, `jsonb_path_ops`), SQL/JSON path (12), constructors and `IS JSON` (16), `JSON_TABLE`, `JSON_EXISTS`, `JSON_QUERY`, `JSON_VALUE` (17). [JSON types](https://www.postgresql.org/docs/18/datatype-json.html), [17 release notes](https://www.postgresql.org/docs/17/release-17.html) |
| UUID | No UUID type (request closed "won't fix"); `BINARY(16)`. `GEN_UUID()` produces version 4. **`GEN_UUID(7)` is merged for 6.0**, not in any 5.0.x. [#6842](https://github.com/FirebirdSQL/firebird/issues/6842), [#7980](https://github.com/FirebirdSQL/firebird/issues/7980), [PR #8167](https://github.com/FirebirdSQL/firebird/pull/8167) | `uuid` type; `gen_random_uuid()` (13); **`uuidv7()` and `uuidv4()` new in 18**; `uuid_extract_timestamp()` (17, handles v7 since 18). [UUID functions](https://www.postgresql.org/docs/18/functions-uuid.html), PG-RN18 |
| Partitioning | None (request open since 2005). 6.0 brings tablespaces, which place tables in separate files but do not partition. [#1159](https://github.com/FirebirdSQL/firebird/issues/1159), FB-ROAD | Declarative partitioning (range, list since 10; hash, default partition, keys and indexes since 11). [Partitioning](https://www.postgresql.org/docs/18/ddl-partitioning.html) |
| Parallelism | 5.0: parallel backup, restore, sweep and index creation, **off by default** (`MaxParallelWorkers = 1`). **No parallel query execution** (request open since 2009). FB-RN50, FB-CONF, [#3114](https://github.com/FirebirdSQL/firebird/issues/3114) | Parallel query since 9.6 (scans, joins, aggregates), parallel B-tree index builds (11), parallel GIN builds (18); asynchronous I/O new in 18 (`io_method = worker` by default). [Parallel plans](https://www.postgresql.org/docs/18/parallel-plans.html), PG-RN18 |

## Operations

| Topic | Firebird | PostgreSQL |
| --- | --- | --- |
| Replication | Built in since 4.0: logical (record level), primary to replicas, synchronous or asynchronous through journal files. FB-RN40 | Streaming (physical) replication (9.0), synchronous (9.1), logical (10), failover slots and `pg_createsubscriber` (17). [High availability](https://www.postgresql.org/docs/18/high-availability.html) |
| Failover | Manual promotion (`gfix -replica none`); no automatic failover built in. Commercial: HQbird Cluster Manager. FB-RN40, [HQbird](https://ib-aid.com/en/start/) | Not built in ("PostgreSQL does not provide the system software required to identify a failure"); open source tools Patroni (MIT), CloudNativePG (Apache 2.0), repmgr, pg_auto_failover. [Failover](https://www.postgresql.org/docs/18/warm-standby-failover.html), [Patroni](https://github.com/patroni/patroni), [CloudNativePG](https://github.com/cloudnative-pg/cloudnative-pg) |
| Backup | `gbak` (logical, online, parallel since 5.0, encrypted since 4.0), `nbackup` (physical, incremental levels). FB-RN50, [nbackup](https://firebirdsql.org/file/documentation/html/en/firebirddocs/nbackup/firebird-nbackup.html) | `pg_dump` (logical), `pg_basebackup` (physical), incremental backups (17); tools pgBackRest (MIT), Barman, WAL-G. [Backup](https://www.postgresql.org/docs/18/backup.html), [pgBackRest](https://github.com/pgbackrest/pgbackrest) |
| Point-in-time recovery | **None built in**: nbackup restores the states of the backups taken; replaying the replication journal has no stop at a time or position. [replication.conf 5.0.4](https://github.com/FirebirdSQL/firebird/blob/v5.0.4/builds/install/misc/replication.conf), [nbackup](https://firebirdsql.org/file/documentation/html/en/firebirddocs/nbackup/firebird-nbackup.html) | WAL archiving plus base backup, recovery to a time, transaction or named point. [Continuous archiving](https://www.postgresql.org/docs/18/continuous-archiving.html) |
| Observability | `MON$` tables (snapshot per transaction; compiled statement cache new in 5.0), trace API, SQL and PSQL profiler (5.0). No cumulative per-statement statistics, no wait events. FB-RN50 | `pg_stat_activity` with wait events, `pg_stat_statements`, `pg_stat_io` (16), `EXPLAIN ANALYZE` with buffers by default (18), `auto_explain`. [Monitoring](https://www.postgresql.org/docs/18/monitoring-stats.html), [pg_stat_statements](https://www.postgresql.org/docs/18/pgstatstatements.html), PG-RN18 |
| Extensibility | UDR: functions, procedures and triggers in native code (C++, Pascal/Delphi) since 3.0; plugins for authentication, encryption, trace, replication. UDFs deprecated since 4.0. FB-RN30, FB-RN40 | Extensions (`CREATE EXTENSION`), foreign data wrappers, procedural languages (PL/pgSQL, PL/Python, PL/Perl, PL/Tcl), own types and index methods. Known extensions: PostGIS, pgvector, TimescaleDB, Citus. [Extending SQL](https://www.postgresql.org/docs/18/extend.html) |
| Embedded and footprint | Embedded mode with the normal client library (3.0), one file per database, downloads of 17 to 27 MB (Windows, Linux, macOS, Android; no Windows ARM64). FB-RN30, [Downloads](https://firebirdsql.org/en/firebird-5-0/) | Client/server only, a process per connection; no embedded mode in the project (third party: PGlite, a WASM build, alpha). Routine vacuuming, mostly automatic. [Architecture](https://www.postgresql.org/docs/18/tutorial-arch.html), [Vacuuming](https://www.postgresql.org/docs/18/routine-vacuuming.html), [PGlite](https://github.com/electric-sql/pglite) |
| Managed cloud services | None at AWS (RDS, Aurora), Google Cloud (Cloud SQL) or Azure; only VM images (e.g. DigitalOcean 1-Click "HQbird Firebird v4.0"). [RDS](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Welcome.html), [Cloud SQL](https://docs.cloud.google.com/sql/docs/introduction), [Azure databases](https://azure.microsoft.com/en-us/products/category/databases), [DigitalOcean](https://docs.digitalocean.com/products/marketplace/catalog/hqbird-firebird-v4-0/index.html.md) | 18 at AWS (RDS, Aurora), Google (Cloud SQL, AlloyDB), Azure (Flexible Server), plus Neon, Crunchy Bridge, Aiven, DigitalOcean, Heroku and others. [RDS versions](https://docs.aws.amazon.com/AmazonRDS/latest/PostgreSQLReleaseNotes/postgresql-versions.html), [Cloud SQL versions](https://cloud.google.com/sql/docs/postgres/db-versions), [Azure versions](https://learn.microsoft.com/en-us/azure/postgresql/configure-maintain/concepts-supported-versions) |
| Development community | Last 12 months on `master` (4 Nov 2025 to 4 Nov 2026): 751 commits without merges by about 28 authors; four of them wrote 79 %. October 2026: crowdfunding of US$20,000 for QA because 93 pull requests wait for review. Own analysis of the [repository](https://github.com/FirebirdSQL/firebird), [Crowdfunding](https://firebirdsql.org/en/news/crowdfunding-to-improve-firebird-qa) | Large contributor base; commits on the GitHub mirror are not comparable (committers instead of authors). Not counted here. |
